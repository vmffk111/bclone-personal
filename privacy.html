개인정보처리방침

시행일: 2026년 10월 24일. 개인 PC에서 실행하는 bclone 및 로컬 Cloud Copy의 개인용 Google Drive 연결에 적용됩니다.

승인된 범위에서 파일 이름, 식별자, 크기, 수정 시각 등의 메타데이터와 선택한 파일 내용을 폴더 조회, 비교, 다운로드, 업로드, 복사 및 폴더 생성에 사용합니다. 연결 계정 확인에 필요한 식별 정보도 로컬에서 확인할 수 있습니다. 전체 Drive 권한에는 파일 수정·삭제 권한도 포함될 수 있습니다.

토큰과 설정은 소유자의 PC에 보관하며 Google 인증·API 서버와 통신하는 데 사용합니다. 캐시와 전송 로그 보관은 로컬 설정에 따릅니다. 이 안내 사이트는 인증 정보나 클라우드 파일을 수신·보관하지 않습니다.

다른 클라우드로 복사하도록 지시한 경우 선택한 파일과 필요한 메타데이터가 그 서비스로 전송됩니다. 데이터를 판매·대여하거나 광고 또는 범용 AI 모델 학습에 사용하지 않습니다. Google API 데이터의 이용·전송은 Google API Services User Data Policy의 Limited Use 요구사항을 준수합니다.

The use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Google 계정 연결 관리에서 접근을 철회할 수 있습니다. 철회해도 이미 저장된 로컬 설정·캐시·로그나 목적지의 복사본은 자동 삭제되지 않으므로 소유자가 별도로 관리·삭제해야 합니다.

이 정적 사이트에는 자체 추적·광고·분석 스크립트나 입력 양식이 없습니다. 호스팅 제공자는 접속 IP 등 기술 정보를 처리할 수 있습니다. GitHub 개인정보처리방침이 적용됩니다.
